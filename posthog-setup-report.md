# PostHog post-wizard report

The wizard has completed a deep integration of PostHog analytics into the Pika Master Planning Backend (FastAPI). A new `posthog_client.py` module was created in `backend/app/core/` using the instance-based `Posthog()` API with `enable_exception_autocapture=True`. PostHog is initialized in the FastAPI `lifespan` context manager on startup and flushed on shutdown. Environment variables `POSTHOG_PROJECT_TOKEN` and `POSTHOG_HOST` are set in `backend/.env` and loaded via `python-dotenv`. Ten events were instrumented across six route files, covering the full parent journey: login → memory pipeline → weekly plan → feedback → schedule customization.

| Event | Description | File |
|---|---|---|
| `user_logged_in` | A parent logs in using an access code, resolving to a dataset/profile. | `backend/app/api/routes/reasoning.py` |
| `memory_analysis_completed` | Memory analysis LLM pipeline completes for a child profile. | `backend/app/api/routes/analyze_memory.py` |
| `plan_from_analysis_generated` | Weekly plan generated from a completed memory analysis (admin pipeline). | `backend/app/api/routes/analyze_memory.py` |
| `weekly_plan_generated` | A full weekly plan is generated by the AI planner for a child profile. | `backend/app/api/routes/weekly_plan.py` |
| `plan_feedback_submitted` | A parent submits a star rating and optional comment on the weekly plan. | `backend/app/api/routes/weekly_plan.py` |
| `eval_session_created` | A new evaluation session is created for a child profile. | `backend/app/api/routes/eval_sessions.py` |
| `eval_session_step_updated` | An evaluation session advances to the next step in the onboarding flow. | `backend/app/api/routes/eval_sessions.py` |
| `planner_memory_processed` | The full memory pipeline (conversations → observations → insights) runs for a profile. | `backend/app/api/routes/planner_memory.py` |
| `memory_saved` | A parent manually edits and saves memory clusters or talk history. | `backend/app/api/routes/planner_memory.py` |
| `schedule_config_saved` | A parent saves their customized daily session schedule configuration. | `backend/app/api/routes/schedule_config.py` |
